⏳ Preloader Project

A simple animated preloader created for my personal website development practice while learning frontend development.

📌 Overview

This project is a beginner-level web animation (preloader) built during my early learning phase of web development in November 2024. It was created while I was experimenting with building websites using Google Sites and learning HTML/CSS basics.

The goal of this project was to understand how loading animations work and how they can improve user experience in websites.

🛠️ Tech Used
HTML
CSS
Basic JavaScript
AI-assisted code generation (ChatGPT, used for learning support)
🎯 What I Learned
How preloaders work in websites
Basic animation concepts in CSS
Editing and customizing generated code
Understanding how frontend components behave in real use cases
⚠️ Challenges Faced

While trying to integrate this preloader into Google Sites, I faced limitations such as:

No proper support for custom preloaders
Full-screen overlay issues when embedding code
Compatibility limitations of platform

Because of these issues, the project was not deployed in the final website and remains a learning experiment.
